# Louisville Sangh Parushan Agent

An agent used during Paryushan 2026 for individuals for their daily fasts logging, announcements in group, etc. happening over Whatsapp using Twilio.

## Overview

This project provides a WhatsApp bot powered by Twilio that helps participants track their fasting progress, receive announcements, and stay connected during the Paryushan 2026 celebration.

## Features

- Daily fast logging
- Group announcements
- WhatsApp integration via Twilio
